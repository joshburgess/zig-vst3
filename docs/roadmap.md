## Current Focus

`zig-vst3` is the raw VST3 API package. `zig-vst3-plugin` is the higher-level plugin framework package. Both are now exercised by validator-passing example bundles and the public CI matrix.

Near-term work should stay focused on finishing release confidence before adding broad new features:

- Keep the Zig version pinned in `docs/toolchain.md` and CI. Update it only through a dedicated PR.
- Keep the VST3 SDK version pinned in `scripts/fetch_sdk.*` and documented in `docs/toolchain.md`.
- Keep host smoke results in `docs/host-matrix.md`.
- Keep public API docs synchronized with framework changes.

Polar point and extent rendering select excluded speakers from nominal positions and redistribute their gain power through tolerance-grouped layer, front/back, and distance priorities. DirectSpeakers rendering now applies the complete ordered common-layout mapping table before ordinary exact-label, bounded-position, LFE, and point-panner fallback. The mapping recognizes the supported common input packs, mirrors lateral rules, enforces input and output layout restrictions, requires every destination label, composes block gain into allocation-free multi-output mixing, and falls through without changing the existing route when no rule is complete.

`AdmMatrixCoefficientMixer(Sample, maximum_delay_samples)` retains the standards-conformant constant-gain and rounded-delay path. `AdmVariableMatrixCoefficientMixer(Sample, maximum_delay_samples, maximum_variables, maximum_points, maximum_phase_taps)` adds an explicit product-policy path for named gain, phase, and delay variables. ## Non-goals

- Hosting plugins. This project builds plugins, not hosts.
- VST2 compatibility.
- A mandatory GUI toolkit. VSTGUI is an optional reference adapter, and users can provide another toolkit.
- Plugin sandboxing or out-of-process hosting.
